## 📂 Projects

### 📱 Phone Number Detector

A Python tool that checks whether a phone number matches the simplified formats supported for India, Australia, and New Zealand. More countries and features will be added over time.

**Status:** 🚧 In Progress

### 🎲 Roll the Dice

A simple command-line dice rolling game built using Python. The program generates a random number between 1 and 6, allowing the user to roll the dice repeatedly until they decide to stop playing.

**Features:**
- Roll a six-sided die.
- Roll again as many times as you want.
- Exit the game whenever you like.

**Concepts Practiced:**
- Python's `random` module
- `random.randint()`
- User input and output
- `while` loops
- Conditional statements (`if`)

**Status:** ✅ Completed — Beginner Version

### 🪨 Rock Paper Scissors

A simple command-line game where you play Rock Paper Scissors against the computer. The computer randomly picks a choice, and the program determines the winner.

**Features:**
- Play using rock, paper, or scissors.
- See both the player's and computer's choices.
- Get the result after each round.
- Play multiple rounds or exit the game.

**Concepts Practiced:**
- Python's `random` module and `random.choice()`
- Lists and dictionaries
- User input and validation
- `while` loops and conditional statements
- f-strings and emojis

**Status:** ✅ Completed — Beginner Version
