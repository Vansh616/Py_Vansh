# 🔢 Guess The Number

A simple command-line number guessing game built using Python. The computer randomly picks a number between 1 and 100, and the player tries to guess it.

## How to Run

Make sure Python 3 is installed, then run:

```bash
python number_guessing_game.py
```

## How to Play

- Guess a number between 1 and 100.
- Type a number to make your guess.
- Get a hint if your guess is too high or too low.
- Keep guessing until you find the correct number.

## Concepts Practiced

- Python's `random` module
- `random.randint()`
- User input and type conversion using `int()`
- `while` loops
- Conditional statements (`if`, `elif`, `else`)
