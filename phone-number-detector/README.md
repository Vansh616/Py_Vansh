# 📱 Phone Number Detector

A Python project that checks whether a phone number matches the simplified mobile-number formats supported by the program.

## 🌍 Supported Countries

- 🇮🇳 India
- 🇦🇺 Australia
- 🇳🇿 New Zealand

## ✨ Features

- Validates user input
- Requires at least 9 digits
- Checks whether the input contains digits only
- Detects the possible country based on the number format
- Displays the corresponding country code

## 🔍 How It Works

The program first validates the input and then checks it against the
supported country patterns.

Example:

```text

Input:
6367454456

Output:
This number is a possible Indian mobile number.
