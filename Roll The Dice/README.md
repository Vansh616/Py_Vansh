# 🎲 Roll the Dice

A simple command-line dice rolling game built using Python. This beginner-friendly project generates a random number between 1 and 6 each time the user rolls the dice. I'll keep improving this project and adding new features as I learn more Python.

## ✨ Features

- 🎲 Roll a virtual six-sided die.
- 🔁 Roll the dice multiple times.
- ⛔ Stop playing whenever you want.
- 🎯 Generate random results using Python.

## 🛠️ Technologies Used

- **Language:** Python 3
- **Module:** `random`

## 🎮 How to Play

1. Run the program.
2. Type `y` when asked to roll the dice.
3. The program will display a random number between 1 and 6.
4. Type `y` to roll again or another response to stop playing.

## 💻 Example Output

```text
Roll the dice? (y/n): y
You rolled a 4.
Roll the dice again? (y/n): y
You rolled a 2.
Roll the dice again? (y/n): n
Thanks for playing!
Goodbye!
```

*Note: Dice results will vary each time you play.*
